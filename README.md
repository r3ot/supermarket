# AISLE™ Creative Agency

A premium creative agency portfolio website featuring an interactive shopping cart experience with 3D product visualization.

## 🎨 Features

- **Interactive Shopping Cart**: Add/remove creative services with real-time price calculations
- **3D Product Visualization**: Rotating 3D models of services using Three.js
- **Receipt-Styled Design**: Unique retail-inspired interface with barcode elements
- **Smooth Animations**: GSAP scroll animations and transitions
- **Responsive Design**: Mobile-friendly interface that works on all devices
- **Service Catalog**: Six core creative services:
  - Brand Identity Kit ($4,800)
  - Website Design ($7,200)
  - Motion Design Package ($3,600)
  - Brand Strategy ($5,500)
  - Artisanal Copy ($2,400)
  - Social Content Package ($1,800)

- **HTML5** - Semantic markup
- **CSS3** - Custom properties, grid layouts, animations

- **GSAP** - Animation and scroll triggers
- **Google Fonts** - Bebas Neue, Courier Prime, Space Mono

## 💡 Key Features Explained

### 3D Product Rendering
Each service is rendered as a 3D object (boxes, cans, tubes) with custom label textures that update dynamically based on the service data.

### Shopping Cart System
- Add services to cart
- View real-time totals with tax calculation (8.5%)
- Remove items with visual feedback
- Animated notifications

### Scroll Animations
Products and sections animate into view as you scroll, creating an engaging browsing experience.
